###Passport OCR

Мобильное приложение для распознавания текста с фотографий паспорта гражданина Российской Федерации и отправки извлечённых данных по электронной почте в виде защищённого паролем архива 7z.

###Возможности

Получение изображения паспорта с помощью мобильного устройства.

Распознавание текста на русском языке с использованием EasyOCR.

Отправка распознанного текста на сервер.

Создание архива 7z с защитой паролем.

Отправка архива на указанный адрес электронной почты.

Удаление временных файлов после обработки запроса.

###Архитектура

Приложение состоит из двух частей:

Flutter-клиент — получает изображение, взаимодействует с пользователем и отправляет запросы на сервер.

Flask-бэкенд — распознаёт текст, формирует защищённый архив и отправляет его по электронной почте.

Общий сценарий работы:

Пользователь получает изображение паспорта.

Мобильное приложение отправляет изображение на endpoint /ocr.

Сервер распознаёт текст и возвращает результат.

Пользователь указывает адрес электронной почты и пароль архива.

Приложение отправляет распознанный текст и параметры отправки на endpoint /upload.

Сервер создаёт архив 7z и отправляет его по электронной почте.

###Требования

Для запуска бэкенда:

Docker

Для запуска мобильного приложения из исходного кода:

Flutter SDK

Android SDK

Android-устройство или эмулятор

Для отправки электронной почты необходим доступ к SMTP-серверу и корректные учётные данные.

Запуск бэкенда

Перейдите в каталог бэкенда:

cd backend

Соберите Docker-образ:

docker build -t passport-ocr-backend .

Создайте файл .env в каталоге backend и укажите параметры SMTP:

SMTP_HOST=smtp.example.com
SMTP_PORT=587
SMTP_FROM=your-email@example.com
SMTP_PASSWORD=your-smtp-password

Значения выше приведены для примера. Укажите параметры своего почтового сервиса.

Не добавляйте файл .env в Git: он содержит конфиденциальные настройки.

Запустите контейнер:

docker run --rm \
  --name passport-ocr-test \
  --env-file .env \
  -p 5000:5000 \
  passport-ocr-backend

После запуска Flask-сервер будет доступен на порту 5000 компьютера.

При первом запуске EasyOCR может загружать необходимые модели. Дождитесь сообщения о готовности OCR.

###Остановка

Для остановки контейнера нажмите Ctrl+C в терминале, где он запущен.

Запуск Flutter-приложения на Android

Перейдите в корневой каталог проекта:

cd ..

Проверьте подключение устройства:

adb devices

При подключении через USB можно перенаправить порт бэкенда на Android-устройство:

adb reverse tcp:5000 tcp:5000

В таком режиме приложение может обращаться к локальному серверу по адресу:

http://localhost:5000

Убедитесь, что базовый URL API в приложении настроен соответствующим образом.

Запустите приложение из корневого каталога Flutter-проекта:

flutter pub get
flutter run

Примечание: перенаправление ADB используется для локальной разработки и тестирования. При подключении через Wi-Fi необходимо настроить доступ к серверу по IP-адресу компьютера в локальной сети. Сам Docker-образ от способа подключения телефона не зависит.

###API

POST /ocr

Распознаёт текст на изображении.

Тип запроса: multipart/form-data.

Поле:

file — изображение для распознавания.

Пример запроса:

curl -X POST \
  -F "file=@passport.jpg" \
  http://localhost:5000/ocr

При успешной обработке сервер возвращает JSON с распознанным текстом.

POST /upload

Создаёт защищённый архив с распознанным текстом и отправляет его по электронной почте.

Тип запроса: application/json.

Поля:

text — распознанный текст.

email — адрес получателя.

password — пароль для защиты архива.

Пример запроса:

{
  "text": "Пример распознанного текста",
  "email": "recipient@example.com",
  "password": "example-archive-password"
}

При успешной отправке сервер возвращает JSON со статусом операции.

Проверка работоспособности

Рекомендуемый сценарий проверки:

Запустить Docker-бэкенд.

Подключить Android-устройство и настроить ADB-перенаправление либо обеспечить сетевой доступ к серверу.

Запустить Flutter-приложение.

Получить изображение паспорта и проверить распознавание текста.

Указать адрес электронной почты и пароль архива.

Отправить архив.

Убедиться, что письмо получено.

Открыть архив с правильным паролем и проверить содержимое.

Проверить, что неверный пароль не позволяет получить содержимое архива.

###Безопасность

SMTP-учётные данные передаются через переменные окружения.

Файл .env не должен попадать в репозиторий.

Архив защищается паролем, указанным пользователем.

Временные файлы удаляются после обработки запроса.

Приложение предназначено для демонстрации распознавания текста и обработки данных. Перед использованием с реальными паспортными данными необходимо отдельно оценить требования к защите персональных данных, безопасной передаче и хранению информации.
