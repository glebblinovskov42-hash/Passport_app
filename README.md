#  Passport OCR

**Passport OCR** — мобильное приложение для распознавания текста с фотографий паспорта гражданина Российской Федерации и отправки извлечённых данных по электронной почте в виде защищённого паролем архива `.7z`.

##  Возможности

-  **Получение изображения паспорта** с мобильного устройства.
-  **Распознавание текста** на русском языке с помощью EasyOCR.
-  **Мобильный интерфейс** для взаимодействия с пользователем.
-  **Создание защищённого архива `.7z`** с паролем, заданным пользователем.
-  **Отправка архива по электронной почте** через SMTP.
-  **Удаление временных файлов** после обработки запроса.

##  Архитектура

Проект разделён на две основные части:

- **Flutter-клиент** — получает изображение, отображает результат распознавания и отправляет данные на сервер.
- **Flask-бэкенд** — распознаёт текст, создаёт защищённый архив и отправляет его по электронной почте.

### Сценарий работы

1. Пользователь выбирает или фотографирует паспорт.
2. Приложение отправляет изображение на сервер через `POST /ocr`.
3. Сервер распознаёт текст и возвращает результат.
4. Пользователь указывает адрес электронной почты и пароль архива.
5. Приложение отправляет данные через `POST /upload`.
6. Сервер создаёт архив `.7z` и отправляет его получателю.

##  Запуск бэкенда

### **1. Перейдите в каталог backend**

Из корневого каталога проекта выполните:

```bash
cd backend
```

### **2. Настройте переменные окружения**

Создайте файл `.env` в каталоге `backend`:

```dotenv
SMTP_HOST=smtp.example.com
SMTP_PORT=587
SMTP_FROM=your-email@example.com
SMTP_PASSWORD=your-smtp-password
```

Укажите реальные настройки своего почтового сервиса. Приведённые значения — примеры, а не рабочие учётные данные.

>  **Важно:** не добавляйте `.env` в Git. Файл содержит конфиденциальные настройки.

### **3. Соберите Docker-образ**

```bash
docker build -t passport-ocr-backend .
```

### **4. Запустите контейнер**

```bash
docker run --rm \
  --name passport-ocr-test \
  --env-file .env \
  -p 5000:5000 \
  passport-ocr-backend
```

После запуска API будет доступен на порту `5000` компьютера.

>  При первом запуске EasyOCR может загружать необходимые модели. Дождитесь сообщения о готовности OCR.

### **5. Остановите бэкенд**

Чтобы остановить контейнер, нажмите `Ctrl+C` в терминале, где он запущен.

##  Запуск Flutter-приложения

### **1. Перейдите в корневой каталог**

Откройте новый терминал:

```bash
cd ~/passport_ocr_app
```

### **2. Установите зависимости**

```bash
flutter pub get
```

### **3. Подключите Android-устройство**

Включите отладку по USB и проверьте подключение:

```bash
adb devices
```

### **4. Настройте подключение к API**

При локальном тестировании через USB можно использовать ADB-перенаправление:

```bash
adb reverse tcp:5000 tcp:5000
```

В таком режиме приложение обращается к серверу по адресу:

```text
http://localhost:5000
```

Убедитесь, что базовый URL API в Flutter-приложении соответствует этому адресу.

### **5. Запустите приложение**

```bash
flutter run
```

> **Примечание:** ADB-перенаправление предназначено для локальной разработки и тестирования. При подключении через Wi-Fi можно использовать IP-адрес компьютера в локальной сети, если сервер доступен по этому адресу и соединение не блокируется брандмауэром.

## API

### **`POST /ocr` — распознавание текста**

Принимает изображение в формате `multipart/form-data`.

**Параметры запроса:**

| Поле | Тип | Описание |
|---|---|---|
| `file` | File | Изображение для распознавания |

**Пример запроса:**

```bash
curl -X POST \
  -F "file=@passport.jpg" \
  http://localhost:5000/ocr
```

При успешной обработке сервер возвращает JSON с распознанным текстом.

### **`POST /upload` — создание и отправка архива**

Принимает JSON с распознанным текстом, адресом получателя и паролем архива.

**Параметры запроса:**

| Поле | Тип | Описание |
|---|---|---|
| `text` | String | Распознанный текст |
| `email` | String | Адрес электронной почты получателя |
| `password` | String | Пароль для защиты архива |

**Пример тела запроса:**

```json
{
  "text": "Пример распознанного текста",
  "email": "recipient@example.com",
  "password": "example-archive-password"
}
```

При успешной обработке сервер возвращает JSON со статусом операции.

##  Проверка работоспособности

Рекомендуемый сценарий проверки:

1. Запустить Docker-бэкенд.
2. Подключить Android-устройство и настроить доступ к API.
3. Запустить Flutter-приложение.
4. Получить изображение паспорта и проверить распознавание текста.
5. Указать адрес электронной почты и пароль архива.
6. Отправить архив.
7. Убедиться, что письмо получено.
8. Открыть архив с правильным паролем и проверить содержимое `passport.txt`.
9. Проверить, что неправильный пароль не позволяет извлечь содержимое архива.

##  Безопасность

- SMTP-настройки передаются через переменные окружения.
- Файл `.env` не должен попадать в репозиторий.
- Архив защищается паролем, заданным пользователем.
- Временные файлы удаляются после обработки запроса.

**Важно:** приложение обрабатывает персональные данные. Перед использованием с реальными паспортными данными необходимо отдельно оценить требования к их защите, передаче и хранению.
